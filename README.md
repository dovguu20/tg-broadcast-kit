# Розсилка в Telegram-групи

## Для учня

Це програма, яка сама надсилає твоє оголошення в Telegram-групи. Нічого встановлювати
руками не треба. Ти готуєш кілька речей, а далі помічник **Grok Bot** робить решту.

**Що приготувати**

1. Оплачений сервер. У листі від хостера будуть адреса (IP) і пароль. Система — Ubuntu.
2. Окремий акаунт Telegram для розсилки, не твій основний. На ньому увімкни Telegram Premium, хмарний пароль
   і задай ім'я користувача @... (Налаштування → Ім'я користувача).
3. Два ключі з сайту https://my.telegram.org — заходь туди саме з акаунта розсилки.
4. Свій числовий id: з основного акаунта напиши боту @userinfobot, він пришле число.
5. Застосунок Grok Bot (x.ai/bot) і підписка, в яку він входить (SuperGrok, X Premium або платний Cursor).

**Що написати помічнику**

Відкрий Grok Bot і встав це повідомлення цілком:

```
Ось комплект розсилки: https://github.com/dovguu20/tg-broadcast-kit
Прочитай у ньому файл GROK.md і постав мені розсилку за цією інструкцією від початку до кінця.
Я не програміст. Веди мене простими словами, по одному кроку.
Паролі, ключі, номер, код і хмарний пароль питай через приховане поле, не в чат.
```

Пароль сервера, ключі, номер телефону, код з Telegram і хмарний пароль в чат не пиши.
Помічник попросить їх окремо, у полі, де символи не видно.

**Ще один акаунт** ставиться на той самий сервер. Підготуй для нього те саме (акаунт з Premium,
хмарним паролем і @username, його власні ключі з my.telegram.org) і напиши помічнику:
«Додай на мій сервер ще один акаунт розсилки за GROK.md».
